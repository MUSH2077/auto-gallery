# Gallery font sources

All fonts are distributed under the SIL Open Font License. Preserve the adjacent license files with their resources.

- Italianno: https://github.com/google/fonts/tree/main/ofl/italianno. The local Latin-subset WOFF2 is distributed from https://fonts.gstatic.com/s/italianno/v18/dg4n_p3sv6gCJkwzT6RXiJwo.woff2. License: italianno-OFL.txt.
- Fraunces: https://github.com/undercasetype/Fraunces. typography/fraunces/fraunces-variable.woff2 retains the variable optical size, weight, softness and wonk axes. License: typography/fraunces/OFL.txt.
- Noto Serif SC: https://github.com/notofonts/noto-cjk. typography/noto-serif-sc contains the local WOFF2 subsets with the upstream unicode-range coverage. License: typography/noto-serif-sc/OFL.txt.
- LXGW WenKai: https://github.com/lxgw/LxgwWenKai. typography/wenkai contains the local 400 and 500 WOFF2 resources. License: typography/wenkai/OFL.txt.

Relative CSS URLs bundle the resources with their consumers. The typography rules retain their optical-size, variation and synthesis settings.
