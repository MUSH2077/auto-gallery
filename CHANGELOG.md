# Changelog

All notable changes to auto-gallery will be documented in this file.

The project follows a practical pre-1.0 versioning model:

- Breaking database or API changes are called out explicitly.
- Provider compatibility changes mention affected sources.
- Deployment changes mention required Docker Compose or `.env` updates.
