# Changelog

All notable changes to auto-gallery are documented here. The project uses
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) categories and
practical pre-1.0 semantic versioning.

## [Unreleased]

### Added

- Multi-user administration with module permissions, preferences, and manual
  upload quotas.
- Manual media upload with validated file types, metadata import, and task
  tracking.
- Creator-first repositories, repository tag views, animated tag bubbles, and
  creator-to-repository storage breakdowns.
- Cross-source, asset-level visual deduplication with evidence scoring,
  reviewable ambiguous matches, grouping, quarantine, and recoverable storage
  state.
- Responsive navigation, command palette, page context navigation, overflow
  handling, accessible object lists, and reduced-motion behavior.
- Public contribution, support, security, repository-ruleset, CodeQL, and
  release-governance materials.

### Changed

- X/Twitter directory and metadata import now normalize physical `twitter`
  extractor data to the `x` domain identity.
- Subscription and other dynamic collection views share consistent list,
  action, hierarchy, and entrance behavior.
- Documentation now matches the current Docker Compose services, frontend
  structure, manual upload support, test commands, and automatic migrations.

### Security

- Added privacy-safe release checks, private vulnerability reporting guidance,
  CodeQL analysis, Dependabot coverage, and protected-branch templates.
