# Support

auto-gallery is community-maintained and does not provide a response-time or
availability SLA.

## Where to ask

- Reproducible product bugs: use the **Bug report** issue form.
- Docker Compose or NAS deployment problems: use **Deployment help**.
- Source compatibility and new extractor requests: use **Provider request**.
- Product improvements: use **Feature request**.
- Security vulnerabilities: report privately through
  [SECURITY.md](SECURITY.md), never in a public issue.

Before opening an issue, search existing reports and reproduce on the default
branch or latest beta where practical.

## What to include

- auto-gallery commit or tag
- OS/NAS, Docker Engine, and Docker Compose versions
- affected provider and public sample URL, when relevant
- concise reproduction steps and expected behavior
- sanitized logs and configuration differences

Do not attach `.env`, cookies, tokens, private creator URLs, private media,
database dumps, or full gallery-dl configuration. Replace usernames, host
paths, hostnames, and account identifiers with neutral placeholders.

Questions about obtaining content, bypassing platform restrictions, or using
credentials that are not yours are outside the project's support scope.
